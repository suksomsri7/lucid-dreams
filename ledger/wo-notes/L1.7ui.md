## 4. หนี้ / ข้อควรรู้ที่บันทึกไว้ในโค้ด (ของเดิมจาก builder คนแรก ผมตรวจสอบแล้วว่าตรงจริง)

ทุกจุดนี้มี comment อ้างถึงโน้ตนี้ไว้แล้วในโค้ด (ตอนนี้มีไฟล์นี้จริงแล้ว):

- **วลีกระซิบหลังทำนองยังไม่เรนเดอร์** (`src/audio/anchor.ts` header) — `POST /ai/tts` (server-side TTS, cache ตาม `anchorPhraseKey`) ยังไม่มีฝั่งแอปเรียก ไฟล์นี้เล่นแค่ทำนอง (tone) เท่านั้น
- **SecureStore vs AsyncStorage** (`src/api/client.ts` header) — เลือก AsyncStorage เก็บ device token เพราะ SecureStore ไม่มี implementation บนเว็บ และโมดูลนี้ต้องรันได้ (harmlessly) ในบันเดิล QC เว็บที่ `?fixture=` ชนะเสมอก่อนโค้ดนี้จะรัน — token ไม่ใช่ความลับที่มี blast radius เกิน "เรียก `/ai/plan` แทนเครื่องนี้ได้" (คีย์ API จริงไม่เคยออกจากเซิร์ฟเวอร์) จึงยอมรับความเสี่ยงนี้ได้
- **DND check เป็น stub คืน `true` เสมอ** (`src/platform/dnd.ts`) — ไม่มี public API ของ Expo SDK 57 อ่านสถานะ Focus/DND ที่มีผลต่อ *เสียง* (ต่างจาก *การแจ้งเตือน*) ได้ ต้องมี native module — งานนี้ note ไว้ว่าเป็นของ "Opus audio WO" (ตามที่ WO นี้เขียนกำกับไว้ในสัญญาเอง)
- **wake-time ยังไม่มีช่องตั้งค่า** (`app/plan/devices.tsx` — `evaluateReadiness` ต้องการ `wakeAtIso`) — ใช้ `now + 8 ชม.` แบบ hardcode ชั่วคราวเพราะยังไม่มี UI ตั้งเวลาตื่นในแอปเลย (ไม่ใช่ของ WO นี้)
- **seed ลายน้ำเสียงต่อเครื่อง** (`src/audio/anchor.ts`'s `getAnchorSeed`) — งานนี้ปิดช่องที่ WO ก่อนหน้าไม่ได้ทำ (ไม่มี field seed ใน `src/store/onboarding.ts`) ด้วยวิธีปฏิบัติ: สุ่มครั้งแรกแล้วเก็บ AsyncStorage รอด reinstall app ไม่รอด (ต้องมี server-side identity ถึงจะรอด reinstall จริง)
- **1-ใน-4 คืนควบคุม (control night) ยังไม่ implement** (`src/data/night.ts`'s `ensureNightSession`) — `mode` เป็น `'CUE'` เสมอ ตอนนี้ยังไม่มี WO ไหนสร้างตัวสุ่มเลือกจริง
- **`CategoryCard`/`SearchOtherRow`-ทำนอง ซ้ำกันระหว่าง `onboarding/devices.tsx` (L1.3) กับ `plan/devices.tsx` (WO นี้)** — ตั้งใจไม่ดึงรวมเป็นโมดูลเดียว เพราะทั้งสองไฟล์เป็น screen component ไม่ใช่ shared module; ทิ้งไว้เป็นโอกาสทำในภายหลัง (hoist เป็น `src/devices/CategoryCard.tsx`)
- **`playOneShot` บน iOS มี timeout กันค้าง** (4 วิสำหรับ anchor clip, 8 วิอื่น ๆ) เผื่อ `didJustFinish` ไม่ยิง — ไม่เคยเจอเคสจริงที่ต้องพึ่ง timeout นี้ระหว่างทดสอบ (รันบน web stub เท่านั้น ไม่มี iOS device ทดสอบจริง)
- **`withInfoPlistLocales`/`withDataProtection` ยืนยันด้วย `expo prebuild` เท่านั้น** — ไม่มี Mac/Xcode บน VPS นี้ ไม่เคยรัน build จริงเทียบ ยืนยันแค่ไฟล์ที่ generate ออกมาถูกต้อง (`.entitlements` มีคีย์ตามที่ตั้งใจ)

**ไม่มีข้อขัดแย้ง (disagreement) กับสัญญา WO นี้** — งานของ builder คนแรกตรงสัญญาครบ ผมแค่ตรวจสอบ+รันข้อสอบ+แก้บั๊ก 1 จุดที่หลุดมาจาก QC ด้วยตา
