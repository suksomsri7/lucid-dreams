# ใบงาน L3.13 — R1 hotfix #4: พูดแทนพิมพ์ (Speech-to-Text iOS)

เจ้าของ 25 ก.ย. 2026 16:43 (TestFlight build 2): กดไมค์ในห้องที่ปรึกษา → "This device cannot do that yet"
สาเหตุ: `src/platform/ios/IosPeripherals.ts#IosSpeechToText` เป็น **stub** (`isAvailable → false`, `start → throw`) คอมเมนต์บอกว่า "expo-speech-recognition is added in L1.6" แต่ไม่มีใบไหนทำ · หน้าเช้า (`useMorning.ts`) ใช้ตัวเดียวกัน ⇒ เล่าฝันด้วยเสียงก็ใช้ไม่ได้เช่นกัน · ข้อความ InfoPlist (ไมค์/Speech) มีอยู่แล้วใน app.config

## งาน builder (native → ต้อง build #8)
1. `cd apps/mobile && npx expo install expo-speech-recognition` (57.x · dep เดียวที่อนุญาต) · เพิ่ม plugin ใน `app.config.ts`: `['expo-speech-recognition', { microphonePermission: MICROPHONE_PERMISSION, speechRecognitionPermission: <ข้อความ NSSpeechRecognitionUsageDescription เดิม> }]` (ห้ามเปลี่ยนถ้อยคำ — L1.3 แปลไว้ใน InfoPlist.strings แล้ว)
2. `src/platform/ios/IosSpeechToText.ts` (ไฟล์ใหม่) implement `SpeechToText` (`src/platform/types.ts` §5):
   - `isAvailable()` → `ExpoSpeechRecognitionModule.isRecognitionAvailable()` (+ `getStateAsync` ถ้ามี) · false บน simulator/ไม่มีเครื่องมือ
   - `requestPermissions()` → `requestPermissionsAsync()` ทั้งไมค์+speech → `granted`
   - `start({locale})` → `ExpoSpeechRecognitionModule.start({ lang: options.locale, interimResults: true, continuous: false, requiresOnDeviceRecognition: <true เมื่อ supportsOnDeviceRecognition() และ locale อยู่ใน supportsRecognition on-device> , addsPunctuation: true })` · ถอยเป็น server-based เมื่อ on-device ไม่รองรับภาษานั้น (ไทยบางเครื่องไม่รองรับ on-device) และ **บันทึกลง audio event/console ว่าใช้โหมดไหน** (DESIGN §0.5 S4: ควรอยู่ในเครื่อง)
   - `stop()` → `stop()` · `onResult(listener)` → event `result` → `{ text: results[0].transcript, isFinal }` ตามชนิด `SpeechResult` ที่มี · `onError` → event `error` (`code`, `message`) และ `end` โดยไม่มี final → error 'NO_SPEECH'
   - ลบ stub เก่าออกจาก IosPeripherals.ts · ต่อเข้า `native.ios.ts`
3. UX ห้องที่ปรึกษา (`AdvisorRoom.tsx` + `Composer` ถ้าจำเป็น): กดไมค์ → ขอสิทธิ์ครั้งแรก · กำลังฟัง = ปุ่มไมค์เต้น/เปลี่ยนเป็นสี acc + ข้อความเล็ก `advisor.mic.listening` "กำลังฟัง… แตะอีกครั้งเพื่อหยุด" · partial แสดงในช่องพิมพ์ทันที (แทนที่ draft) · final → ส่งเป็นข้อความผู้ใช้ (`fromVoice: true` มีอยู่) · ถูกปฏิเสธ → `advisor.mic.denied` "ไม่ได้รับสิทธิ์ไมค์/รู้จำเสียง" + ปุ่ม เปิด Settings (`Linking.openSettings`) · ไม่รองรับ → `advisor.mic.unavailable` (แทนข้อความ common.notAvailableOnThisDevice เดิม) · ทั้ง th/en
4. หน้าเช้า (`useMorning.ts`) ใช้ interface เดิม — ไม่แตะ logic นอกจากที่จำเป็นให้ partial/final ทำงาน
5. Android/web: `native.android`/web ยังคง stub เดิม (rule 8) · fitness ต้องผ่าน
