## งาน builder (apps/mobile เท่านั้น · ห้ามแตะ engine/api/assets)
### A `src/audio/seedRemote.ts`
- `SEED_AUDIO_VERSION = 'george-1'` · `ensureSeedLineUri(text, lang)`: ไฟล์ `Paths.cache/seed/<sha1(text|lang|version)>.mp3` มี → uri · ไม่มี → `fetchTtsAudio({text, lang, voice:'whisper'})` (เพิ่มใน `src/api/client.ts` แบบเดียวกับ `fetchAnchorAudio` · timeout 15 s · ตรวจ content-type audio/mpeg · ขนาด ≥ 8 KB) → เขียนไฟล์ → uri · ล้ม → null (ไม่ throw) · เว็บ → null
- `prefetchSeedLines(plan, lang)`: ทั้ง 2 ประโยค in-flight เดียว · เรียกที่ (1) `useAdvisor.start()`/หลัง `saveTonightPlan` (2) `AdvisorRoom.handleStart` (3) `startNightSession` ก่อน `startBed`
- `clearSeedCache()` เมื่อ `resetAnchorSeed` ไม่จำเป็น (ประโยคไม่ผูกกับ seed) — ไม่ต้องทำ

### B `src/night/session.ts`
- ติดตาม `currentBedVolume` จาก `startBed(BED_VOLUME_FULL)` และทุก `SET_BED_VOLUME`
- SEED action: `const uri = await ensureSeedLineUri(plan.seedLines[i], lang)` (แคชเท่านั้นก็ได้ถ้าเน็ตช้า: ใช้ timeout รวม ≤ 3 s) → ถ้ามี: duck (`setVolume(BED_DUCK_SEED)`) → `playOneShot({source: uri, volume: SEED_VOLUME, pan: 0})` → `setVolume(currentBedVolume)` · บันทึก `recordNightCue(... type:'SEED', played: <จริง>)` (เดิม hardcode true)
- PLAY_CUE: duck ก่อน `playAnchorOnce` → `BED_DUCK_CUE` · หลังจบ (promise resolve) คืน `currentBedVolume` (ถ้าเป็นไปได้ค่อย ๆ 3 ขั้นภายใน 3 s)
- ค่าคงที่ `SEED_VOLUME = 0.35`, `BED_DUCK_SEED = 0.06`, `BED_DUCK_CUE = 0.03` (ไว้ใน `src/audio/mix.ts` หรือ session.ts)
- อย่าให้ seed เล่นทับ anchor/cue (ไม่มีทางชนตามเวลา แต่กัน race ด้วย flag `oneShotBusy`)
